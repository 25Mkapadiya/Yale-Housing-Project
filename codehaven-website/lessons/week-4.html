Lesson Plans/Week 4

Topics: Variables, Conditionals

Code Haven Week 4

Week 4 Overview

Objectives

  • Introduce the concept of variables
  • Practice using variables in Scratch
  • Ensure that students know when to use variables in their coding

Materials and Resources

  • Materials needed: Envelopes, slips of paper for each student
  • Lesson Plan
  • Worksheet
  • Worksheet Solution
  • Presentation

Lesson Plan Overview

  1. 10 minIntroduction: Review loops and conditionals
  2. 10 minUnplugged Activity: Mad Libs activity!
  3. 5 min[Optional] Live Coding: Demonstrate variables in Scratch, use "ask" and "join" blocks
  4. 30 minWorksheet: Log into Scratch accounts and work on the worksheet
  5. 5 minWrap up: See how variables fit with the maze activity

Worksheet

Part 1: Scratching an Itch!

Let’s have the Scratch Cat keep track of how many times we hover over him!

  1. First, set up the program so that it starts when we click the flag and runs forever. We should also set the variable to 0 at first.
  2. Next, create a conditional that runs if the pointer is touching Scratch.
  3. Finally, complete the conditional to make the variable increase, and then wait a second!

Part 2: Count Scratchula!

Scratch is already keeping track of how many times we touch him, but he should be able to tell us how many! When we press the spacebar, Scratch should say “You touched me ___ times!” and then reset his count.

  1. Create a new conditional that runs if we press the spacebar!
  2. When we do, Scratch should say how many times we touched him, and then reset the variable.

Part 3: A Visit to Dr. Scratch!

The Scratch cat is hungry! Eating cake makes him more powerful, but running into a pufferfish hurts him. Let’s keep track of his health level!

  1. First, set up the program so that it starts when we click the flag and runs forever. We should also set Scratch’s health variable to 10, and make him draggable.
  1. Next, create two conditionals that run if Scratch runs into the cake or the pufferfish.
  2. Finally, complete each conditional to make the variable increase or decrease.
  1. Add another conditional to have Scratch say “Power up!” if his health gets too low. He should then reset his health to 10.

Questions to Discuss

  • Can you change your drawing so that it uses two loops?
  • How else can we use randomness to make your drawing even more unique?
