Worksheet

Part 1: Moving in Scratch!

Let’s make the Scratch cat move up, down, left, and right with arrows!

  1. Make the program run forever when the flag is pressed
  2. Make four conditionals, one for each arrow button that can be pressed
  3. Add the correct direction inside each arrow conditional
Question: How are we using coordinates to make the Scratch cat move?

Part 2: Splatter Painting!

Let's keep working on the last part! When we press the spacebar, Scratch should go somewhere random. Also, Scratch should use the pen to make cool drawings as he moves!

  1. Click the + button to give Scratch a pen.
  2. Inside our loop from the last activity, add one more conditional to check if the spacebar is pressed!
  3. When it is, Scratch should move randomly.
  4. Outside our loop, make Scratch put the pen down!

Part 3: Apple Chasing!

Don't get rid of your last project yet — it's time to make a game! Whenever Scratch runs into the apple, he should get a point, and the apple should run away from him!

  1. Add a new sprite with the + Sprite button!
  2. We need a new variable 'score.' When we click the flag, the score should be set to 0.
  3. Then, we should have a loop that runs forever, checking each time if Scratch is touching the apple.
  4. When he is, he should get a point and the apple should move!
