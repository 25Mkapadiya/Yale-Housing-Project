Challenge Worksheet

Make a start page!

We want to welcome people to our maze, so let’s make a start screen!

  1. First, choose a new backdrop for your maze by pressing the button in the bottom right corner.
  2. Then, play around with these blocks to make a start page!

Make a “you win” page!

Let’s reward our players for beating the maze with a “you win” screen. It’s very similar to making a start page, so use the blocks above!

Add a points system!

When players get to the end or touch an object, they should get a point!

  1. First, make your own variable by pressing the make a variable button under the variables tab.
  2. Then, think about when you want your cat to earn points! For example, you could earn points when you win, when you touch a certain object, or when you press a certain keyboard key.
  3. Set up a conditional that will check if this has happened, and then increases the points variable!

Add more levels!

This is a tricky one! Here are some questions to think about:

  1. When should my cat play a new level?
  2. Should the rules be different in the new level?
  3. How is the code similar in the new level?
