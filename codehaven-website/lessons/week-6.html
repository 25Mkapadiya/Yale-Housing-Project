Lesson Plans/Week 6

Topics: Game Design

Code Haven Week 6

Week 6 Overview

Objectives

  • Apply coordinates to the game design process!

Materials and Resources

  • Materials needed: None
  • Lesson Plan
  • Worksheet
  • Week 6/7 Completed Maze
  • Presentation

Lesson Plan Overview

  1. 5 minIntroduction: Review coordinates and explain the maze game
  2. 5 min[Optional] Live Coding: Work through parts 1 and 2 of the worksheet together
  3. 45 minWorksheet: Log into Scratch accounts and work on the worksheet
  4. 5 minWrap up: Review worksheets and see how far students got

Worksheet

Part 1: Getting Our Maze!

Get your very own copy of the maze game to build on this week.

Your maze should look like this!

  1. Go to tinyurl.com/Code-Haven-Maze-Game
  2. Click the See Inside button
  3. Sign in to your Scratch account
  4. Click the Remix button
  5. Rename your project “Maze Game”

Part 2: Moving in Scratch!

Let’s make the Scratch cat move up, down, left, and right with arrows!

  1. Make the program run forever when the flag is pressed.
  2. Make four conditionals, one for each arrow button that can be pressed
  3. Add the correct direction inside each arrow conditional

Part 3: From the Window…

When Scratch runs into a wall, he should teleport back to the start!

  1. The blocks below should go in Scratch’s forever loop!
  2. We should have a conditional that runs when Scratch hits the wall color, sending him to the start and making him say a sad message.

Part 4: Field Goal!

When Scratch gets to the green area, he should say an encouraging message!

  1. Add one more conditional that runs when Scratch gets to the end!
  2. Write a fun message for him to say to the game player :)
